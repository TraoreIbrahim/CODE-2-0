# Documentation de CODE 2.0

CODE 2.0 est un assistant vocal personnel, libre et auto-hébergé. Ces pages expliquent comment l'installer, le régler et s'en servir au quotidien. Les exemples utilisent le nom d'assistant par défaut, « Nova ».

- [Installation](installation.md) : les prérequis, l'installation sur macOS, Windows et Linux, le premier lancement, le serveur seul et le build.
- [Configuration](configuration.md) : les variables d'environnement du serveur, le fichier `config/code.config.ts` et `npm run secrets`.
- [Clés API](cles-api.md) : abonnement ou clé API, les fournisseurs de modèles et de voix, où coller les clés, ce que cela coûte.
- [Modèle local](modele-local.md) : CODE 2.0 avec Ollama, sans clé payante pour le modèle.
- [Google](google.md) : relier Gmail, Agenda et Drive avec votre propre projet Google Cloud.
- [Téléphone](telephone.md) : la web app du téléphone, l'association par QR, le HTTPS et les notifications.
- [Voix](voix.md) : l'empreinte vocale, le choix des voix et de la transcription, les heures de silence.
- [Sécurité](securite.md) : ce que l'assistant peut faire seul, ce qui attend votre « oui », et où vivent vos secrets.
- [Dépannage](depannage.md) : les problèmes fréquents et leurs solutions.
- [Feuille de route](FEUILLE-DE-ROUTE.md) : les étapes du projet.
